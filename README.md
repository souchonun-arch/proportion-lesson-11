| 學習目標 | 對應內容 |
|---|---|
| 知道「比例」是甚麼 | 兩個比值相等的比組成的等式 |

## 🎮 兩種使用模式

### 📚 學生自學模式（預設）
- 每題都有 **💡 老師提示** 與 **📖 概念框**
- 答錯時顯示**完整詳解**，並自動記錄到「錯題回顧」
- **答錯可以重試** —— 看過詳解後按鈕會解鎖，再試一次
- 結算畫面顯示：總分、答題數、最高連對、正確率、逐題錯題回顧

### 🎯 課堂搶答模式
- 每關開始 **30 秒倒數**（最後 5 秒紅色閃爍＋提示音）
- 內建**學生登記表**：輸入姓名登記，按「✅ 答對 +10」計分
- **排行榜**自動排序（金、銀、銅牌）
- 倒數結束會提示老師可揭示答案

## 📌 教材對齊說明

- **教材原文**：所有題目數據與答案均按教育出版社 M6A_11 原文。
- **第 9 頁龜兔賽程 (a)(b)** 課本未印答案，網頁答案以精確分數重算核實：
  `15 : 2 = 7.5 ≠ 50 : 5 = 10`；`15 : 50 = 3 : 10 ≠ 2 : 5 = 4 : 10` —— **兩題皆為「不能組成比例」**。
- **挑戰題**「用 16、8、4 和 2 可以組成多少個不同的比例？」答案為 **8 個**（四個不同的數能組成比例時，一共可組成 8 個不同的比例），網頁內附完整清單與推理提示。
- **人物名稱**：教材為「少傑」，已對齊。
- **語體**：全頁使用繁體中文書面語。
